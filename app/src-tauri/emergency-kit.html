Tiga versi sebelumnya disimpan di folder yang sama sebagai vault.rahsa.1 sampai .3.

Memulihkan di laptop baru

  1. Siapkan file backup rahsa-backup-YYYYMMDD.rahsa dari flashdisk atau drive lain.
  2. Pasang aplikasi Rahsa, lalu pilih Pulihkan dari backup di layar pertama.
  3. Pilih file backup dan masukkan master password.
  4. Pasang ekstensi Rahsa di Chrome dan pasangkan ulang dengan kode 6 digit.

Penting

Tanpa master password, isi vault tidak bisa dibuka oleh siapa pun, termasuk pembuat aplikasi. Tidak ada pintu belakang.
