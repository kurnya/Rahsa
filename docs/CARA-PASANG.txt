CARA MEMASANG RAHSA
===================

Isi paket ini:

  - Rahsa_<versi>_x64-setup.exe : aplikasi desktop untuk Windows 10/11 (64-bit)
  - ekstensi-chrome\ : ekstensi untuk Google Chrome
  - CARA-PASANG.txt : panduan ini


1. PASANG APLIKASI
------------------

  1. Jalankan Rahsa_<versi>_x64-setup.exe. Tidak perlu hak admin.
  2. Jika muncul "Windows protected your PC", klik "More info", lalu
     "Run anyway". Peringatan ini muncul karena installer belum
     ditandatangani dengan sertifikat berbayar.
  3. Buka Rahsa dari Start Menu, buat master password, lalu simpan
     Emergency Kit.


2. PASANG EKSTENSI CHROME
-------------------------

  1. Salin folder "ekstensi-chrome" ke tempat yang TIDAK akan dihapus
     atau dipindah, misalnya C:\Rahsa\ekstensi-chrome
     Chrome memuat ekstensi langsung dari folder ini, jadi jangan
     memakainya langsung dari folder Downloads atau dari dalam zip.
  2. Buka Chrome, ketik chrome://extensions di address bar.
  3. Nyalakan "Developer mode" (pojok kanan atas).
  4. Klik "Load unpacked", lalu pilih folder ekstensi-chrome tadi
     (folder yang berisi file manifest.json).
  5. Klik ikon puzzle di toolbar Chrome, lalu pin "Rahsa".

  Chrome kadang menampilkan peringatan tentang ekstensi mode developer.
  Itu normal untuk ekstensi yang tidak dipasang dari Chrome Web Store.


3. PASANGKAN EKSTENSI DENGAN APLIKASI
-------------------------------------

  1. Pastikan aplikasi Rahsa terbuka dan vault sudah dibuka kuncinya.
  2. Klik ikon Rahsa di Chrome, lalu klik "Pasangkan".
  3. Cocokkan kode 6 digit di popup dengan yang tampil di aplikasi,
     lalu klik "Kodenya sama, pasangkan" di aplikasi.


4. MULAI PAKAI
--------------

  1. Di aplikasi: "Tambah institusi" (nama + link halaman login),
     lalu "Tambah akun".
  2. Di popup ekstensi Chrome, klik "Izinkan" untuk situs tersebut.
  3. Klik "Masuk" pada kartu akun.

  Ekstensi hanya bekerja selama aplikasi Rahsa terbuka.


MEMPERBARUI KE VERSI BARU
-------------------------

  Aplikasi : jalankan installer versi baru. Data tetap aman di
             %APPDATA%\id.rahsa.desktop\
  Ekstensi : salin isi folder ekstensi-chrome yang baru ke folder yang
             SAMA (timpa isinya), lalu klik tombol reload pada kartu
             Rahsa di chrome://extensions. Pairing tidak perlu diulang.


PENTING
-------

  - Master password TIDAK BISA DIPULIHKAN oleh siapa pun. Simpan
    Emergency Kit dan buat backup rutin
    (Pengaturan > Backup & pemulihan).
  - Rahsa hanya mengisi password di alamat https yang Anda daftarkan
    persis sama.
